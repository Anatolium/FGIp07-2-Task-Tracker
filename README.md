# Таск-трекер команды

Внутренний веб-таск-трекер для небольшой команды: канбан-доска с 4 статусами, две роли,
серверное хранение данных, история изменений, комментарии, поиск, фильтры и CSV-экспорт.

Реализовано по ТЗ `ТЗ-2.md`.

## Стек и почему так

- **Бэкенд:** Node.js (>= 22.5) без единой внешней зависимости — встроенные `node:http`,
  `node:sqlite`, `node:crypto`. Ничего не нужно скачивать из сети, `npm install` не требуется.
- **БД:** SQLite (файл `data/tracker.db`, WAL-режим). Данные хранятся на сервере.
- **Фронтенд:** один статический SPA-клиент (`public/`) на нативном HTML/CSS/JS без сборки.

## Запуск

```bash
npm start          # http://127.0.0.1:3000
PORT=8080 npm start  # другой порт
npm test           # интеграционные тесты API
```

При первом запуске создаётся база с демо-данными.

## Роли и права

Права проверяются на сервере для каждого запроса — клиент не является источником истины.

| Действие | Руководитель | Сотрудник |
| --- | --- | --- |
| Видеть задачи | все | только назначенные на себя |
| Создавать задачу | да | нет (403) |
| Удалять задачу | да | нет (403) |
| Менять название/описание/срок | да | да, только у своих задач |
| Назначать исполнителя | да | нет (403) |
| Ставить любой статус | да, включая `Готово` | только `Новая` / `В работе` / `На проверке` |
| Комментировать | да | да, только свои задачи |
| Управлять пользователями | да | нет (403) |
| CSV-экспорт | все задачи | только свои |

Лимит аккаунтов — 10. Нельзя удалить или разжаловать последнего активного руководителя
и заблокировать собственную учётную запись.

## Статусы канбана

`new` → `in_progress` → `review` → `done`

Перетаскивание карточек мышью (HTML5 drag & drop) и кнопки-стрелки на карточке для мобильных.

## Одновременная работа и конфликты

У каждой задачи есть счётчик версии (`version`). Любое изменение отправляет текущую версию,
и сервер применяет его только если версия совпадает (optimistic concurrency control).

- при рассинхронизации сервер отвечает `409 Conflict` и возвращает актуальные данные;
- клиент показывает предупреждение, обновляет доску и переоткрывает задачу с новыми данными;
- доска в фоне раз в 20 секунд подтягивает изменения коллег.

## API

Аутентификация — сессионная cookie `tracker_sid` (HttpOnly, SameSite=Lax, 12 ч),
также принимается `Authorization: Bearer <token>`. Пароли хранятся как `scrypt`-хеши с солью.

| Метод | Путь | Доступ | Назначение |
| --- | --- | --- | --- |
| POST | `/api/login` | — | вход, выдаёт сессию |
| POST | `/api/logout` | вход | выход, гасит сессию |
| GET | `/api/me` | вход | текущий пользователь |
| GET | `/api/tasks` | вход | список задач с фильтрами (`q`, `status`, `assignee`, `due`) |
| POST | `/api/tasks` | руководитель | создать задачу |
| GET | `/api/tasks/:id` | участник задачи | задача + комментарии + история |
| PATCH | `/api/tasks/:id` | участник задачи | изменить (обязательно поле `version`) |
| DELETE | `/api/tasks/:id` | руководитель | удалить |
| GET/POST | `/api/tasks/:id/comments` | участник задачи | комментарии |
| GET | `/api/tasks/:id/history` | участник задачи | история изменений |
| GET | `/api/export.csv` | вход | CSV-экспорт (UTF-8 BOM, разделитель `;`) |
| GET | `/api/users` | руководитель | список аккаунтов |
| POST | `/api/users` | руководитель | создать аккаунт |
| PATCH | `/api/users/:id` | руководитель | имя/роль/пароль/блокировка |
| DELETE | `/api/users/:id` | руководитель | удалить аккаунт |

Фильтр `due`: `overdue` (просроченные), `today`, `week` (ближайшая неделя), `set`, `none`.
Фильтр `assignee`: `me`, `none` или id пользователя.

## Структура

```
server/index.js       HTTP-сервер, статика, graceful shutdown
server/api.js         маршруты API, права доступа, валидация, CSV
server/db.js          схема SQLite и демо-данные
server/auth.js        сессии
server/password.js    scrypt-хеширование
server/rules.js       правила ролей (единственный источник правды по правам)
server/http-util.js   хелперы запросов/ответов
public/               SPA-клиент (index.html, styles.css, app.js)
tests/api.test.js     интеграционные тесты API
data/tracker.db       база данных (создаётся автоматически)
```
