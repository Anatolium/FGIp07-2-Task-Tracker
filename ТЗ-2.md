### 1. Цель проекта
Создать отдельное веб-приложение — простой внутренний таск-трекер для небольшой команды.  
Сотрудник видит только свои задачи, руководитель — исполнителей, сроки и движение работы по одному согласованному процессу.

### 2. Пользователи и роли
- Количество аккаунтов: до 10
- Роли (строго 2):
  - Руководитель — управляет пользователями, видит все задачи, может назначать исполнителей и менять любые статусы
  - Сотрудник — видит и работает только со своими задачами в рамках выданных прав

### 3. Основной функционал (MVP)

Рабочая область
- Одна рабочая область (без нескольких проектов/пространств)

Канбан-доска
- 4 статуса: `Новая` → `В работе` → `На проверке` → `Готово`
- Перетаскивание карточек между статусами
- Возможность одновременного редактирования (базовая обработка конфликтов)

Карточка задачи
- Название
- Описание
- Срок выполнения
- Ответственный (исполнитель)
- Комментарии
- История изменений

Дополнительные возможности
- Поиск по задачам
- Фильтры (по статусу, исполнителю, сроку)
- CSV-экспорт задач
- Создание и редактирование задач
- Изменение статуса
- Отказ в доступе при попытке выполнить действие вне прав роли

### 4. Авторизация и безопасность
- Вход по логину + паролю
- Защита всех действий по ролям
- Серверное хранение данных

### 5. Интерфейс
- Адаптивный дизайн: корректная работа на компьютере и телефоне
- Чистый и понятный интерфейс без лишних элементов

### 6. Что не входит в проект
- Диаграмма Ганта
- Учёт рабочего времени
- SSO
- Мобильные приложения в магазинах
- Интеграции с Jira / 1С
- Круглосуточная поддержка

### 7. Критерии готовности MVP
- Есть две роли с разными правами
- Работает канбан с 4 статусами
- Можно создавать задачи, назначать исполнителя, ставить срок, писать комментарии
- Ведётся история изменений
- Работают поиск, фильтры и CSV-экспорт
- Приложение корректно отображается на компьютере и мобильном
- Все данные сохраняются на сервере
- Неавторизованный пользователь и пользователь с недостаточными правами не могут выполнить запрещённые действия
